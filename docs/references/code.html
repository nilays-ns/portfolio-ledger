Code walkthrough

How the project is structured, how the projection engine works, and how to fork or extend it.

Project structure

app/
  index.html    — all markup; no templating engine
  css/
    style.css   — all styles; CSS custom properties for theming
  js/
    app.js      — all logic: state, projections, chart, table, events
  favicon.svg

docs/           — this documentation site
  index.html
  references/
  tutorials/
  css/style.css
  js/nav.js

There is no build step, no bundler, no node_modules. The app is a single HTML file with one CSS file and one JS file. To run it locally, open app/index.html in any browser.

app.js architecture

The entire application is wrapped in an IIFE (immediately-invoked function expression) to avoid polluting the global scope:

(function () {
  // all state, logic, and DOM wiring lives here
})();

Inside the IIFE, the code is organised into these logical sections:

SectionPurpose
StateA single state object holds all mutable data — sliders, milestone years, and the assets array. This is the single source of truth.
FormattersinrFull() and inrCompact() — format numbers into Indian-style currency strings (e.g., ₹12,34,567 or ₹12.35 L).
Projection engineannualContribution(), contributedByYear(), and simulate() — compute projections month-by-month.
Table rendererrenderTable() — builds the asset rows from the state. Attaches inline event listeners for edits and deletions.
Recalculaterecalc() — runs projections, updates milestone panels, updates the chart, and fills per-asset projected values in the table.
Event wiringSlider input handlers, milestone year input handlers, add-asset button, import/export buttons, example loader, column resize handles, tooltip system.

The projection engine in detail

annualContribution(year)

function annualContribution(year) {
  var base = state.monthly * 12;
  if (year <= state.flatYears) return base;
  var cycleIndex = Math.floor((year - state.flatYears - 1) / state.cycleYears) + 1;
  return base * Math.pow(1 + state.stepUpPct / 100, cycleIndex);
}

Returns the total annual contribution for a given year, applying the step-up schedule after the flat period. cycleIndex tells you how many step-up cycles have elapsed — 0 during the flat period, 1 during the first cycle, 2 during the second, and so on.

simulate(years, withContrib)

function simulate(years, withContrib) {
  var balances = {};
  state.assets.forEach(function (a) { balances[a.id] = parseFloat(a.value) || 0; });

  var totalContribPct = state.assets.reduce(function (s, a) {
    return s + (parseFloat(a.contribPct) || 0);
  }, 0);

  var series = [];
  // ... month-by-month loop
  for (var m = 1; m <= years * 12; m++) {
    var year = Math.ceil(m / 12);
    var monthlyTotal = withContrib ? annualContribution(year) / 12 : 0;

    state.assets.forEach(function (a) {
      var r = (parseFloat(a.rate) || 0) / 100;
      var mRate = Math.pow(1 + r, 1 / 12) - 1;  // monthly rate from annual
      var w = totalContribPct > 0 ? (parseFloat(a.contribPct) || 0) / totalContribPct : 0;
      balances[a.id] = balances[a.id] * (1 + mRate) + monthlyTotal * w;
    });

    if (m % 12 === 0) {
      // snapshot total at each year-end
      series.push({ year: year, total: /* sum of balances */, byId: { ...balances } });
    }
  }
  return series; // array of { year, total, byId }
}

simulate() is called twice on every recalc — once with withContrib = true (the "continuing to invest" scenario) and once with withContrib = false (the "stopped today" scenario). The returned series array is indexed by year: series[5] is the snapshot at year 5.

How to fork the project

  1. Clone or download the repo

    Go to github.com/nilays-ns/portfolio-ledger and click "Fork" (GitHub) or "Code → Download ZIP".

  2. Open app/index.html in a browser

    No install, no build. Just open the file. Edit app/js/app.js or app/css/style.css and reload to see changes.

  3. Deploy on Vercel or GitHub Pages

    Connect the repo to Vercel (root directory = app/) or enable GitHub Pages from Settings → Pages → source: app/ folder.

How to add a new column

To add a new per-asset data column (e.g., "Current allocation %"):

  1. Add the field to the default asset object in the state declaration (e.g., allocPct: 0).
  2. Add a <th> to the table header in index.html.
  3. In renderTable(), add a new <td> with an input element and attach an input event listener that writes back to a.allocPct and calls recalc().
  4. If the column shows a computed value (not user input), update it inside recalc() by finding the row via document.querySelector('[data-id="' + a.id + '"] .your-class') and setting its textContent.
  5. Update the export/import logic — the JSON serialiser in the export handler writes state.assets directly, so the new field is included automatically. The import handler maps the parsed JSON back to state; add a fallback (a.allocPct || 0) in case old files don't have the field.

How to change the currency

The currency symbol is hardcoded in two formatter functions at the top of app.js:

function inrFull(n) { ... return sign + '₹' + ...; }
function inrCompact(n) { ... return sign + '₹' + ...; }

Replace '₹' with your currency symbol. The Indian-style number grouping (e.g., 12,34,567) is in inrFull() — replace the regex /\B(?=(\d{2})+(?!\d))/g with /\B(?=(\d{3})+(?!\d))/g for Western-style grouping (1,234,567).

The compact formatter in inrCompact() uses Indian units (L = lakh = 105, Cr = crore = 107). Replace the thresholds and labels for other locales.
