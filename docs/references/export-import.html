Export & Import

Save your plan to a file, reload it later, or hand it to a friend as a starting point.

Exporting your plan

Click the Export button in the top-right of the calculator. Your browser will download a file named portfolio-ledger.json. This file contains your entire plan — all asset rows, all slider values, and the milestone year settings.

Nothing is sent to a server. The export happens entirely in your browser. The file is written locally and never transmitted anywhere.

Importing a plan

Click Import, select a .json file previously exported from Portfolio Ledger, and your plan will be restored exactly — all assets, all settings. The current state is replaced immediately on import.

Use cases

  • Save your work. Since the calculator has no backend, closing the tab loses your data. Export before you close to save a snapshot you can reload anytime.
  • Version your plan. Export once a year (or whenever you make a major change) and keep dated copies as a record of how your assumptions evolved.
  • Share a starting point. Hand someone a pre-filled file with realistic asset classes and return rates so they don't have to start from scratch.
  • Compare scenarios. Build two plans (aggressive vs. conservative return assumptions), export both, and load them in separate tabs to compare projections.

JSON format

The exported file is plain JSON. Here is a fully annotated example:

{
  "monthly": 25000,        // monthly contribution baseline (number)
  "flatYears": 5,          // flat period before step-up (integer)
  "cycleYears": 2,         // step-up cycle in years (integer)
  "stepUpPct": 10,         // step-up percentage per cycle (number)
  "inflation": 6,          // inflation rate for real-terms view (number)
  "milestones": [5, 10, 25], // three milestone years (array of integers)
  "assets": [
    {
      "name": "SIP / mutual funds",  // display label (string)
      "value": 900000,               // current value in your currency (number)
      "rate": 12,                    // expected annual return % (number)
      "contribPct": 45               // contribution weight (number)
    },
    {
      "name": "EPF / PF",
      "value": 600000,
      "rate": 8.2,
      "contribPct": 15
    }
    // ... more assets
  ]
}

Field reference

FieldTypeDescription
monthlynumberMonthly contribution baseline amount.
flatYearsintegerYears before step-up starts (0–15).
cycleYearsintegerHow often (in years) the step-up occurs (1–10).
stepUpPctnumberPercentage increase per cycle, applied to the original baseline.
inflationnumberAnnual inflation rate used for the real-terms display.
milestonesnumber[3]Exactly three milestone years, in any order.
assets[].namestringDisplay label for the asset row.
assets[].valuenumberCurrent value (≥ 0).
assets[].ratenumberExpected annual return percentage.
assets[].contribPctnumberContribution weight (relative, not capped at 100).
The id field is internal. Exported files may contain an id field on each asset — this is an internal identifier used by the calculator's rendering engine. It is ignored on import; a fresh ID is assigned to each asset when loaded.

Editing a file manually

The JSON format is intentionally simple. You can open an exported file in any text editor and change values directly — useful if you want to try a scenario that's outside the slider range, or if you want to script the generation of a starting template.

After editing, save the file and import it back into the calculator. The app does basic sanity checking (missing fields fall back to defaults) but does not validate value ranges.
